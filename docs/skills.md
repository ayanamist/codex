# Skills

For information about skills, refer to [this documentation](https://developers.openai.com/codex/skills).

## 本 fork 的 Skill 配置

可以在用户配置中全局或按工作区设置单个 skill 的启用状态、自动调用策略和产品限制。
Skill 作者也可以在 `SKILL.md` 中使用 `disable-model-invocation` 声明调用策略。

配置示例和优先级见 [中文使用手册](fork/usage/skills.md)。
声明解析、发现路径和缓存契约见 [维护参考](fork/skill-invocation-policy.md)。
