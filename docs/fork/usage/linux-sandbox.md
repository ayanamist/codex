# Linux 沙箱目录清理

Linux 文件系统沙箱使用 bubblewrap 保护工作区中的元数据路径。
当 `.git`、`.agents`、`.codex`、`.aws` 等受保护目录不存在时，
运行沙箱命令可能临时创建空目录作为挂载点；部分只读路径也可能产生空文件占位。

## 正常退出与异常退出

正常情况下，最后一个使用该挂载点的沙箱进程退出后，辅助程序会清理自己创建的空占位。
进程被 SIGKILL、OOM 或崩溃终止时，清理可能来不及执行。

本 fork 会记录成功创建对象的身份。之后再次运行覆盖相同受保护路径的沙箱命令时，
如果已经没有活跃所有者，且对象仍符合身份与空内容检查，可以自动回收它。
无需额外配置开关。

## 哪些目录会保留

- 原先就存在的真实文件或目录。
- 被替换、修改，或已经包含内容的对象。
- 没有身份记录的历史遗留占位。
- 创建成功但尚未完成身份记录时，进程被终止留下的对象。

这项机制依赖后续沙箱运行，不会后台扫描所有目录，也不会递归删除非空目录。
运行中的空挂载点仍可能暂时可见。
看到空目录本身，无法据此判断是哪一次异常退出造成的。

需要包含此实现的 CLI 和沙箱辅助程序才有上述行为。
如果另外指定了独立沙箱可执行文件，也要确认它包含相同实现。

维护细节见 [沙箱清理契约](../sandbox-mount-targets.md)。
